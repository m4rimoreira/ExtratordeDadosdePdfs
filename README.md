# Extrator Os Pdf

Extração de ordens de serviço de PDFs e relatório Word com ranking de cidades.

## Instalação

```bash
python -m pip install -r requirements.txt
```

## Execução

```bash
python os_extractor.py "pasta_com_pdfs" -o relatorio_os.docx
```

> **Privacidade:** não publique PDFs reais de clientes, relatórios contendo dados pessoais, números de telefone ou informações internas da empresa. Use dados fictícios para demonstrações.

> Código recuperado de uma versão anterior do projeto. Ajuste a extração ao formato dos seus PDFs e valide os resultados antes de usar.
